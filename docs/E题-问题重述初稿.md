# 1 问题重述

## 1.1 研究背景

情感预测是具身智能、自然人机交互等领域的重要基础任务。真实交互中的情绪通常同时体现在文本语义、语音韵律、面部表情和肢体动作等多种信号中，单一模态难以完整描述复杂情绪，多模态信息的联合利用有助于提高情感判断的准确性和稳定性。本题以 CMU-MOSEI 英文多模态情感数据为基础，研究文本、语音和视觉信息的特征表达、时间对应关系及其在情感预测中的综合作用。

实际场景中的多模态数据还存在采样频率、特征维度和时间尺度不一致的问题，且画面遮挡、环境噪声、转写失败等情况可能造成某一模态在局部时段不可用。与此同时，预测模型不仅需要给出情感类别和情感强度，还应说明判断主要依据了哪些模态和局部片段。因此，本题围绕“特征提取与时序对齐—模态缺失下的鲁棒预测—完整模态下的可解释预测”三个层次展开，要求建立可复现、可验证并能够输出专项测试结果的数学模型。

## 1.2 问题回顾

题目提供四类数据和材料。附件1为从 CMU-MOSEI 数据集中筛选的100条英文原始视频，分布在37个以 `video_id` 命名的子文件夹中，每个视频片段以 `clip_id.mp4` 命名，视频时长为2.648～34.567 s，并配有标签表。标签表中的 `label` 为连续情感强度，取值为 `[-3,0)`、`0` 和 `(0,3]`，分别表示负向、中性和正向，数值越接近 -3 或 3 表示相应情感越强；`annotation` 给出 Negative、Neutral、Positive 三类文字标签。原始样本及标签不得自行替换、增补、删除或修改。

附件2为可直接用于建模的 CMU-MOSEI 标准化多模态特征文件，包括 `aligned_50.pkl` 和 `unaligned_50.pkl` 两个版本，以及样本标签表。文件按 `train`、`valid`、`test` 三个顶层键组织，字段的同一索引对应同一条样本。对齐版本中，文本、语音和视觉特征的形状分别为 `(N,50,768)`、`(N,50,74)` 和 `(N,50,35)`，三种模态按最多50个相互对应的序列位置组织；非对齐版本中，三者形状分别为 `(N,50,768)`、`(N,500,74)` 和 `(N,500,35)`，文本保持50个位置，语音和视觉保留独立时序，有效长度由 `audio_lengths` 和 `vision_lengths` 给出。主要字段包括样本标识 `id`、原始文本 `raw_text`、文本特征 `text`、可选的 BERT 整数输入 `text_bert`、语音特征 `audio`、视觉特征 `vision` 以及文字极性、三分类标签和连续情感强度标签。`text` 与 `text_bert` 二选一使用，不能将其视为第四种模态。训练、验证和专项测试必须采用同一特征版本。

附件3为模态局部缺失专项测试集，包含无标签特征样本。局部缺失是指一个或多个模态存在特征值全部为零的随机连续序列区间，并不等同于整个模态完全缺失。附件4为可解释性专项测试集，包含无标签的真实场景视频及对应的完整文本、语音和视觉特征，用于将模型识别出的关键证据位置回看至文本片段、语音时段或视觉关键帧。附件3和附件4均配有与附件2对齐版本、非对齐版本相对应的特征组织方式。

根据上述数据和条件，需要解决以下三个问题。

（1）**多模态情感特征提取与时序对齐。** 基于附件1的100条原始视频，建立文本、语音和视觉三种模态的情感特征提取与跨模态时序对齐方案，明确从原始样本处理到标准化时序特征输出的过程、各模态特征的定义与提取方法、序列位置和时间对应规则。允许使用开源工具或预训练模型完成基础特征提取，但需要保证样本编号、模态文件和输出特征一一对应，记录序列位置、有效长度、填充规则及其与原始素材的对应关系，并说明工具版本、模型版本、关键参数、处理日志和复现实验流程。论文还需汇总附件1全部100条样本的特征提取结果，至少包含样本编号、模态类型、原始有效时长、特征维度和对齐粒度；选取至少1个典型样本展示文本片段、语音时段、视频帧段和三类特征的对应关系。问题1生成的100条样本特征文件需随附件提交。

（2）**模态局部缺失条件下的鲁棒情感预测。** 针对文本、语音或视觉模态在部分连续时间段不可用的情况，建立能够稳定输出情感极性和情感强度的多模态预测模型。需要分析缺失模态类型、缺失位置和缺失时长对预测性能的影响，并通过相应的消融或对比实验说明模型的鲁棒性。模型参数应在附件2训练集上学习，模型结构、超参数和决策阈值应依据验证集选择；附件3仅作为无标签专项测试集，用于最终推理预测。分类任务需评价 Accuracy 和 F1，回归任务需评价 MAE 和皮尔逊相关系数，并按题目要求提交附件3的全量预测结果文件。

（3）**可解释性多模态情感预测。** 针对三种模态信息完整但模型决策依据不易追溯的情况，建立能够同时完成情感预测和依据说明的模型。除输出情感极性和情感强度外，还需量化不同模态在当前样本中的作用差异，指出主要参考模态，并定位与判断密切相关的局部证据；证据位置应能够对应到原始文本片段、语音时段或视觉关键帧。论文需给出典型样本解释卡，展示预测结果、三模态作用程度、主要参考模态和关键证据定位，进一步呈现主要参考模态中局部片段的重要性分布以及三种模态作用差异。模型同样在附件2训练集上学习参数，在验证集上选择模型结构、超参数和决策阈值，附件4仅用于最终无标签推理，并需提交其全量预测与解释结果文件。

所有问题的建模原理、求解过程、评价指标、实验结果和分析结论均应在论文正文中完整呈现。参赛队可以对附件2训练集和验证集进行有合理依据的清洗、重采样和标准化，也可以开展消融实验和规律分析；允许使用开源特征提取工具、预训练模型和开源算法框架，但应在论文中标明名称、版本号、使用场景和核心参数。所有建模任务只能使用题目提供的 CMU-MOSEI 系列数据，不得引入其他公开或私有情感数据集参与训练、微调、参数优化、阈值选择或结果统计。提交材料还应包括问题1的100条时序特征文件、问题2和问题3的核心代码、说明文档、模型参数、配置文件及运行环境说明，以及附件3预测 CSV 和附件4预测与解释 CSV。全部附件大小须不超过50 MB，且论文和附件中不得出现参赛单位、队员姓名或队伍编号等身份信息。

## 1.3 研究综述

多模态情感预测通常将文本、语音和视觉信号视为互补信息，研究重点包括模态特征表示、跨模态时间对齐以及多模态融合。针对不同模态采样频率和序列长度不一致的问题，常见思路是先将各模态转换为统一的时序表示，再通过拼接、加权或交互机制形成联合表示；另一类思路保留各模态的原始时间结构，在预测阶段建立跨模态的对应关系。预训练语言表示、声学与视觉描述特征可以降低原始信号处理难度，但其有效长度、填充位置和时间粒度仍需要进行一致性记录和核验。

在模态缺失场景中，固定权重融合容易受到局部信息缺失的影响。已有方法通常从缺失模拟、模态随机丢弃、缺失信息重建、动态权重分配和跨模态知识迁移等方向提高模型的容错能力，适用于研究缺失模态类型、位置或时长变化下的性能规律。对于可解释性任务，常见方法包括基于注意力或贡献度的模态重要性评估、基于扰动或梯度的局部证据定位，以及将重要时间片段映射回文本、语音或视觉输入。不同解释方法在稳定性、可复核性和时间粒度一致性方面仍可能存在差异。

本题同时要求处理时序对齐、局部模态缺失、连续情感强度与离散情感极性，并将预测依据定位到原始证据。因此，研究切入点应同时关注特征接口的一致性、缺失条件下的预测稳定性、分类与回归任务的共同评价，以及解释结果与原始素材之间的可追溯关系。具体文献及其结论需要结合题目所列参考文献进一步补充并核验。
