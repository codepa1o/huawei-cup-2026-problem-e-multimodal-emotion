# 阶段7：附件3推理、交付与解包复验规划

前置条件：阶段6验收通过，冻结模型和已有实现哈希保持一致。只完成问题二，不扩展问题三，不重新训练或调整分类阈值。

## 实施顺序

1. 再核对阶段6验收、冻结文件、3个成员、train标准化与基础编码器版本。导出只含结构和权重的轻量部署参数，去掉优化器状态、机器绝对路径和训练缓存。
2. 只读附件3**对齐版本**，按文件编号自然排序，逐文件SHA256对账；保留文件内0起始行号，形成30条唯一身份。仅取text_bert/audio/vision，不用非对齐版、原始文本或其他信息恢复缺失。
3. 复用冻结的PAD/MASK规范化、编码前掩码、文本编码和标准化。专项支持域未知，不根据尾部全零猜padding，保留未知状态和实际可观测数量；不生成假标签、不再做人工遮挡。
4. eval与inference_mode推理，3成员等权概率/强度集成。输出四列最小CSV、审计CSV和未舍入JSON，记录全空回退与分类/强度符号冲突。CSV为UTF-8 BOM、6位小数。无标签不计算Accuracy/F1/MAE/Pearson。
5. 组织问题二推理包：轻量模型、normalizer、相对路径部署配置、源码、锁定依赖、预测与关键分析结果、SHA256总清单、中文复现说明；不重复打包官方数据和大型BERT权重。明确基础编码器需按固定revision预先获取，本包不是自包含离线包。
6. 检查ZIP路径与清单后解压到独立新目录，用解压源码和轻量模型**重新编码全部30条并推理**，与原始完整checkpoint结果比较未舍入概率/强度及最终CSV。
7. 独立验证数量、身份、字段、掩码、无标签、范围、舍入、权重同一性、源文件、ZIP大小、解包复验和既有阶段不变性，完成运行报告。

## 验收门槛

- 精确30条，逐文件逐行可回查，无重复和漏样；输入输出均只使用aligned接口。
- 概率有限且在[0,1]、行和容差内为1，极性属于Negative/Neutral/Positive且为argmax；强度有限且在[-3,3]。冲突如实记录，不篡改输出。
- 小数导出误差≤5.1e-7；解包重跑容差atol=1e-6、rtol=1e-5，类别一致。
- 所有交付文件经哈希校验；部署路径必须是包内相对路径；不含参赛身份信息或本机用户路径。
- 问题二子包按50,000,000字节保守检查。全题50MB仍需与问题一、问题三最终材料合计，本阶段不宣称全题总包已达标。
- 解包复验使用已安装CPU运行环境和本机固定BERT缓存，不等同于全新机器离线复现。失败保留记录，不覆盖旧实验或悄悄放宽阈值。
