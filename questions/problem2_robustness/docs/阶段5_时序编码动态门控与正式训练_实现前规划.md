## 2. M1模型规格

- text/audio/vision分别映射为64维；文本先LayerNorm，三模态投影ReLU后用可用mask屏蔽偏置。
- 各模态单层GRUCell，输入附原位置k/49、距上个有效位置的间隔/50；第一个有效位置以前一位置=-1计。保留50槽位，不压紧中间空洞。
- 对无观测位置不更新隐状态：`h_k=where(R_k, GRUCell(input_k,h_prev), h_prev)`。历史传递不是新观测，时序池化仍用R屏蔽。
- 掩码注意力池化，全空模态返回零摘要、零时序权重，避免全负无穷softmax。
- 动态门控输入为模态摘要、当前观测数/50、50槽位中最长不可用连续段/50。最后一项包含padding，必须命名“存储位置不可用段”，不叫真实内容缺失率。
- 不向模型输入人工遮挡前的真实长度、原观测掩码或rho_actual，避免专项推理时得不到这些信息；可靠性描述完全由当前输入mask计算。
- M1-gated采用可用模态上的masked softmax；M1-uniform使用相同编码器、池化和双头，仅换为可用模态等权融合。门控分支在uniform中冻结且不参与前向。
- 分类3 logits，强度`3*tanh`。全空输入返回完整train的类别先验和强度均值，融合/时序权重为0，状态单独记录。
- 输出保留融合权重、时序权重及局部状态接口，便于问题三扩展；这些权重不是因果贡献证明。

## 3. 损失与固定选择规则

四模型统一AdamW lr=0.001、weight_decay=0.0001、梯度裁剪1.0、Dropout=0.2、hidden=64。batch先设32，CPU线程先测1；冻结BERT编码batch=8、4线程。

损失为train频率加权CE＋Huber(delta=1)，回归系数1。增强模型每epoch按阶段4计划混合原始输入与缺失输入；不添加一致性或重构损失，保留双头符号冲突率。

max_epochs=40、patience=6。每轮计算clean四指标，以及12个固定缺失条件的有效子集指标；每种条件等权，回退记录另报覆盖率，不算成功缺失。若某条件没有有效样本，报错并停止自动选择，不静默改变权重。

选择分数（不是官方评分公式）：

`S=0.5*F1_clean+0.5*mean(F1_missing)-0.1*(MAE_clean+mean(MAE_missing))/12`。

每模型保存最高S；平分用更低clean/缺失平均MAE，再用较早epoch。按同一S比较四个模型，平分再比MAE、参数量、模型名。选择规则在首轮训练前固定，不保证M1获胜。最终逐模型同时报告原始指标、缺失等权指标和资源开销。

## 4. 实现与运行顺序

1. 新增stage5配置/输入绑定、掩码GRU与门控模块、指标和checkpoint接口；运行原45项与新增边界测试。
2. 合成数据检查全空、内部缺口、未选模态、梯度、注意力归一化与时间位置；真实32条检查损失可下降。
3. 先微基准评估一批GRU前后向及验证耗时；线程数仅依据资源测量设置，不根据指标选择。
4. 运行四个模型的全train正式训练与固定quick早停；每epoch只物化实际需要的新文本键，模型之间共享。
5. 保存best和last checkpoint、优化器/RNG/epoch状态，支持epoch边界续训，拒绝配置/数据绑定不符的恢复。
6. 每个best模型输出9464条验证预测与13条件指标，复算S，检查模型重载与导出一致；原阶段0—4哈希不变。
