# 阶段5代码阅读与复现说明

## 1. 输入与职责边界

问题二直接使用附件2的官方aligned_50特征接口。沿用阶段1冻结BERT文本特征、阶段2观测mask和仅train拟合的A/V标准化、阶段4连续缺失计划。这里的50是官方序列位置，不能无依据解释为视频时长的50等分。

正式训练数据3395条，valid 728条。每轮验证使用clean＋6种模态组合×2种比例×middle位置，共13条件、9464条分配记录。真实有效缺失子集与不可行回退分开统计；不读取test做选模，不运行附件3预测。

## 2. 从哪里阅读代码

| 文件 | 职责 | 关键约束 |
|---|---|---|
| `robust_context.py` | 独立配置、run_id、只读输入绑定 | 阶段0—4产物或源码改变时拒绝复用 |
| `robust_data.py` | epoch计划、分层缺失文本缓存 | 父缓存只读、子缓存追加、LRU返回副本；BERT不扰动训练torch随机流 |
| `robust_models.py` | 掩码GRU、时序池化、均匀/动态融合 | 无效位置跳过状态更新；保留原位置与间隔；全空安全回退 |
| `robust_training.py` | 模型工厂、选模、checkpoint | 固定规则；优化器状态深拷贝恢复，避免验证恢复时污染快照 |
| `robust_evaluation.py` | 全valid逐条预测及权重核查 | 不可用权重为0；融合/时序权重在可用项上归一化 |
| `train_robust.py` | 32条诊断、四模型训练、早停 | 同种子独立初始化；全部3395条；best与last职责不同 |
| `validate_robust.py` | 独立验收 | 重建计划、核验缓存、重载预测、CSV复算、早停轨迹与原产物哈希 |

新增代码的模块说明、关键公式和边界处理均有中文注释；阶段1—4已绑定的代码保持不动。

## 3. 模型里实际发生什么

每模态先投影为64维，再把当前位置`k/49`和距上次有效位置间隔`(k-previous)/50`作为GRUCell附加输入。第一个有效位置的`previous=-1`。遇到不可观测位置时，隐状态只传递、不更新。该位置即使保留了历史状态，也不参与注意力池化。

动态门控使用模态摘要和当前mask的两个统计量：有效数/50、最长连续不可用槽位数/50。不读取遮挡前mask、真实内容长度或人工缺失率。最长不可用段含padding，不能称为真实语义缺失率。M1-uniform保留相同初始化次序和编码器，仅改为可用模态等权融合，未用门控参数冻结。

全空模态输出零摘要，权重为0；全部模态全空时，返回完整train的类别先验和强度均值，标记`all_inputs_unavailable`。模型输出分类logits、强度、融合权重、时序权重和局部隐状态；CSV只持久化必要的预测与融合权重，局部状态不大规模落盘。

## 4. 优化和选模

使用train频率加权交叉熵＋Huber(delta=1)，不加入一致性或重构损失。分类argmax与强度正负可能冲突，因此单独保存`head_sign_conflict`，不把回归输出暗改为分类一致结果。

先固定以下规则再运行，不能观察结果后改规则以保证复杂模型胜出：

`S = 0.5×clean Macro-F1 + 0.5×12条件平均Macro-F1 − 0.1×(clean MAE + 12条件平均MAE)/12`。

每个缺失条件只用`applied=true`子集，clean配对指标用同一ID；另外保存包含回退的全分配集合指标。S不是题目规定的官方评分，也不是测试性能。某条件没有有效样本则报错，不按0分填补或悄悄重分配权重。

同模型先取更高S，容差1e-8内取更低clean/缺失平均MAE，再保留较早epoch。跨模型最终平分再按参数量和模型名固定排序。max_epochs=40，连续6轮不改善停止。输出epoch采用**从0计数**；例如best_epoch=4表示第5轮。

## 5. 缓存和恢复

冻结BERT只使用已核验revision和本地文件，不下载额外语料或情感模型。缺失文本在token/attention层遮挡后重新编码，不复用完整上下文的hidden states当作缺失输入。相同输入键共享缓存；每个增强epoch只补齐实际需要的新键，三个增强模型共享同epoch计划。

`last.pt`保存模型、优化器、torch/numpy/Python随机状态及训练DataLoader生成器状态。恢复单位是**完成的epoch**，中断轮从头重做，不声称任意batch中断后的原位恢复。文件先写临时文件再原子替换；训练目录和缓存有写锁。代码、配置或输入不一致时拒绝恢复，应创建独立output_root开展新实验，不修改绑定绕过检查。

已完成模型再次执行时先校验产物哈希再复用。训练错误不会产生`completed=true`；`latest_run.json`也不代表成功，必须检查最终`validation_report.json`。

## 6. 运行命令与下一阶段

在`questions/problem2_robustness`目录执行：

```powershell
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m src.train_robust
.venv/Scripts/python.exe -m src.validate_robust
```

本轮只运行seed=2026。接口支持`--seed 2027`、`--seed 2028`，这些后续种子只改变模型/训练随机流；增强计划仍使用阶段4锁定的mask_seed，以维持成对对照。阶段6可据此先进行配对多种子重复，再另行设计遮挡种子敏感性实验。未实际执行的种子、全90条件、test和附件3均不得写成已完成。

融合权重只表示本模型的计算机制；问题三仍需另外做遮挡/保留证据的忠实度验证，不能直接当作因果解释。
