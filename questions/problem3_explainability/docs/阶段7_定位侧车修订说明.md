# 阶段7：定位侧车v2需求与修订

初版已覆盖20条预测解释，但06/15强制对齐未走通、标点没有发音时标，另有词典外专名与少数未匹配词。原始预测、归因和初版文件保留，不修改情感模型或解释预算。

v2仅修订来源定位：对未匹配已知词尝试一次固定宽束搜索（beam=1e-80、wbeam=1e-60、pbeam=1e-80、maxhmmpf=-1）；仅当找到更多合法词段时采用。参数依据PocketSphinx官方配置文档，非依据情感输出调优。

标点只能借邻词回看，标记punctuation_neighbor_anchor；OOV/未匹配词优先借左右已对齐词的句段范围，标记unresolved_word_bracket，绝不标为精确词级时间。无邻词可用则继续失败。原文及特殊字符不擅自校正。所有定位仍需人工核验。

产物另存outputs/stage7_mapping_v2；与stage7逐样本数值输出完全一致，仅时间侧车、素材、解释CSV的定位字段和卡片更新。

依据：https://pocketsphinx.readthedocs.io/en/latest/config_params.html 。此工程回溯规则属于自动近似，不证明官方A/V原始特征提取时间被精确恢复。
