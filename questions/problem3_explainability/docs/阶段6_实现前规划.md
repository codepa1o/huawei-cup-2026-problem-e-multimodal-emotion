# 阶段6：验证、比较和冻结

先固定128个valid样本，按真实类别配额并在各类内轮转video_id分散抽样；存储ID和配置哈希后才执行解释，不根据输出选择案例。全部728条valid计算Accuracy/Macro-F1/MAE/Pearson和混淆矩阵。

128条每条执行8组合、局部删除、保持mask的零表示敏感性、三成员稳定性及30种目标/预算/方法的删保比较。组级预算和有效位置数匹配，随机退化单列；各方法同时报告有符号下降、保留误差与全空率，不截断不利指标。

保存逐样本完整输出，比较表和图从这些输出生成；基线敏感性和不稳定情况按实际比例报告。20%展示预算及并列阈值是预先确定的工程选择，本轮不借专项或test改变它们。代码与配置在通过数值／数据门槛后冻结，附件4正式运行必须验证该冻结。
