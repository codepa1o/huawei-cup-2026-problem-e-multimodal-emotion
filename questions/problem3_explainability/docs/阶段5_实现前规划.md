# 阶段5：局部证据与公平对照

采用原文词组联合删除；文本在BERT之前遮挡，A/V同步特征和mask，重跑全网络。分类支持用正Δ排序，回归影响用|Δ|排序。所有可用模态都计算，未观察模态为空。

正式展示预算预设20%，验证比较10/20/30%，不按附件4效果调参。验证范围先固定128个按类别及video_id分散抽取的valid样本。

比较局部遮挡排序、注意力排序和3次随机排序。按每模态所选词组的有效位置数分桶匹配，保证相同词组数和实际有效位置数；随机方案额外尝试匹配连续组段长度结构，若只能复用同一选择则标记退化、不冒充独立随机证据。注意力排序不强制匹配连续形状，报告这一限制。

验证采用跨三模态的全局证据集合，保留实验会删除其余输入；不混用“其余模态保持”的条件指标。局部差值不强行加和到Shapley；提供局部成员Top证据Jaccard稳定性。
