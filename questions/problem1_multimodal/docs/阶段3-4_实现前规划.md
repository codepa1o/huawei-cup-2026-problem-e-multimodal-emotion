# 问题一阶段3—4：50窗对齐与100样本汇总实现前规划

本文是**待实施的设计**，不表示阶段3—4已经完成。输入为现有阶段0—2的 manifest、100个 timeline JSON、100个原始特征 NPZ 和 feature_index。本地校验曾显示100条均通过结构检查；词时间等级为完整词级70、部分词级15、仅片段级15，另有13条片段完全未检出人脸。因此新输出必须带时间精度和缺失掩码。

## 一、范围和最小改动

计划新增一个 src/align_50.py，读取已有产物，生成50窗特征、来源映射和100行汇总；扩展现有 src/validate_outputs.py 校验新产物；给 tests/ 添加一项合成时间轴检查。复用 NumPy、CSV、JSON、TOML，不添框架或训练步骤。原始附件与阶段0—2产物只读；情感标签不参与对齐、阈值选择或缺失策略。

## 二、共同时间轴与聚合公式

每条样本取阶段1 timeline.video_duration_s 为 T_i>0，并与 NPZ 的 clip_text_time[1] 核对。阶段0媒体流时长不重新定义轴。现有5条视频的流时长与解码帧覆盖不一致，故另外记录最后实际解码帧 end_s；不得把超出该末端的时段默认为可用画面。

取 K=50，零基窗号 k=0,…,49，定义 B_ik=[kT_i/K,(k+1)T_i/K)，最后一窗包含 T_i。边界与权重用 float64 计算。源特征 x_j 的有效时间区间 I_j=[a_j,b_j)，窗交叠权重为

\[
w_{kj}=\max(0,\min(B_k^{end},b_j)-\max(B_k^{start},a_j)),\quad
z_k=\frac{\sum_{j:o_j=1}w_{kj}x_j}{\sum_{j:o_j=1}w_{kj}}.
\]

其中 o_j 为源特征观测掩码。分母为0时写入零向量、观测掩码为 false；零只作占位，不代表测得的情感或声音为零。源时间仅在既定容差内裁到 [0,T_i] 并记录，超容差则报错，不静默修正。

### 文本

- 完整/部分词级：只用 text_time_known_mask 与 text_observed_mask 同为 true 的词，以词区间和窗的交叠加权；一词跨多窗就参与多窗。
- 无已定位词的窗写零向量、text_word_observed=false；此掩码也表示没有可定位的词事件。部分词级样本还须注明存在未定位词，不能断言该窗没有讲话。
- 仅片段级：若 clip_text_observed=true，把整段向量复制到50窗，作为粗粒度退化输入；text_clip_fallback=true、text_word_observed=false、text_time_precision=clip。复制不等于50个词时间观测。总 NPZ 同时单存 clip_text。
- 部分词级的空窗不使用整段向量填补，以免把未知词位置伪装成词级定位。

### 音频

用 audio_time 和 audio_observed_mask 做上述加权。25 ms帧每10 ms移动，源帧相互重叠；权重和仅用于特征平均，不能当成不重叠的物理时长。audio_coverage_fraction 要以音频区间交集的**并集长度**除以窗长，最高为1；audio_voiced_fraction 用相同权重平均原 audio_voiced_mask。静音但可解码时 audio_observed=true；无音频来源时才为 false。

### 视觉

现有 vision_time 是被选中的**原视频帧**短区间，直接聚合会给5 Hz序列制造大量空窗。取所选帧实际显示时间 s_j=vision_time[j,0]，以相邻 s_j 的中点划分最近帧代表区；每帧左右最大代表半径固定为 r=1/(2×5)=0.1 s，代表区也不能越过最后实际解码帧 end_s。没有代表区覆盖的窗段保持无来源。此规则是明确的最近采样帧假设，不能写成连续逐帧实测。

视觉628维拆为前52维人脸与后576维全画面，分别加权：全画面使用 vision_observed_mask，人脸只使用 vision_face_mask；最后重新拼接。无人脸窗的前52维为占位零、vision_face_observed=false，但不影响 vision_scene_observed。保留 vision_source_frame_index 追溯视频帧。

## 三、缺失和回溯约定

50个窗均为真实时间窗，不存在尾部填充；若保留 padding_mask，应全部为 false。至少区分：无定位词、整段文本退化、有声/无基频但音频仍存在、音频无来源、无人脸但有画面、全画面无来源。不能用一个 observed_mask 抹平这些状态。

来源映射按 (sample_id,bin_index) 逐窗保存：窗起止秒数、词索引与交叠秒数、声学帧半开索引范围、视觉采样序号和原视频帧号、文本时间精度、缺失原因。声学帧逐个权重可由原始 audio_time 与固定公式重算，不在 JSON 中重复列出所有浮点权重，以控制体积。所有索引须能回查 timeline 与原始 NPZ。

## 四、文件与100行汇总设计

| 计划路径 | 内容 |
|---|---|
| outputs/stage3/features_aligned_50.npz | sample_ids:(100,)；bin_time_s:(100,50,2)；text:(100,50,768)、audio:(100,50,18)、vision:(100,50,628)；clip_text:(100,768)；各模态及人脸/片段退化的布尔掩码、覆盖率、有声比例、三个原始序列长度。只存数值与Unicode数组，支持 np.load(...,allow_pickle=False)。 |
| outputs/stage3/alignment.jsonl | 5000条窗口映射记录，主键为 (sample_id,bin_index)，记录上述来源索引、权重、精度和原因。 |
| outputs/stage4/summary_100.csv | 恰好100行，将现有原始统计与50窗统计联接；降级样本不删行。 |
| outputs/stage4/report.json | 样本覆盖率、窗级模态覆盖、退化/异常分类、文件体积、参数与校验结论。 |

样本顺序以 manifest.csv 为准，不按目录遍历顺序拼接。summary_100.csv 至少含 sample_id、T_s、alignment_level、word_total/word_aligned、三模态原始长度与维度、text_word_bins/text_clip_fallback_bins、audio_observed_bins、vision_scene_bins/vision_face_bins、audio_coverage_mean、vision_face_frame_rate、stage3_status、issue_codes。新增配置只固定 K、视觉代表半径、数值类型与缺失规则；沿用现有 project.toml 和 environment.json，不再建第二套配置。

NPZ的布尔键明确为 text_word_observed_mask、text_clip_fallback_mask、audio_observed_mask、vision_scene_observed_mask、vision_face_observed_mask、padding_mask，形状均为 (100,50)；另有 clip_text_observed:(100,)。音频的 audio_coverage_fraction/audio_voiced_fraction 也是 (100,50)。文本窗“有输入”可由前两个文本掩码作逻辑或得到；“有定位词事件”仅由 text_word_observed_mask 表达，不另存同义字段。vision_face_observed_mask 为 true 必须蕴含 vision_scene_observed_mask 为 true。vision_face_frame_rate 定义为原始检测到人脸的视觉采样帧数 / 原始有效视觉采样帧数；分母为0时留空并记录原因。

## 五、实施顺序与验收门槛

1. 先运行阶段0—2校验；核对100个ID、NPZ字段、源视频帧号和实际解码末端。输入不合格就停止，不批量写“成功”文件。
2. 独立试跑六种边界样本：最短 -mJ2ud6oKI8$_$6，中位 -wny0OAz3g8$_$2，最长 -yRb-Jum7EQ$_$1，仅片段级 -HwX2H8Z4hY$_$2，部分词级 -aqamKhZ1Ec$_$0，无人脸 -HwX2H8Z4hY$_$9。试跑文件不能覆盖正式100样本索引。
3. 留一个合成可运行测试，覆盖词跨窗权重、重叠音频帧平均、5 Hz视觉中点/末端、人脸缺失而场景有效、片段文本退化、零分母掩码。
4. 固定规则后跑全量100条，输出总 NPZ、5000行映射、100行汇总；每条保留状态和原因，不静默丢样本。
5. 扩展校验：ID及顺序与 manifest 一致；数组形状和数值合法；每条50窗连续、首尾为 [0,T_i]；有值必有来源或明确片段退化；映射索引与原时间有效；无人脸不使全画面失效；抽取若干窗按来源重算并在浮点容差内一致。
6. 实测文件体积，再决定后续赛题 ≤50MB 附件的打包方式。当前原始压缩特征约19.7 MiB、全部 outputs 约27.7 MiB；新增对齐总张量的未压缩 float32 数值部分约27 MiB，不能预先声称全部中间文件可直接提交。任何后续量化/压缩均需另测误差并说明读取方法。

完成定义：100条、每条50窗均能加载；三模态值、掩码、来源可相互核验；100行汇总与报告一致。程序结构通过不等于词时间或人脸检测经过人工核实；典型样本听看抽查和对照实验仍须按总解题流程另做。
