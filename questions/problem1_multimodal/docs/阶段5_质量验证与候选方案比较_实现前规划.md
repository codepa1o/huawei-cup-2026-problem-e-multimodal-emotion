# 问题一阶段5：质量验证与候选方案比较——实现前规划

本文是**待实施设计**，不表示人工复核或候选实验已经完成。阶段0—4已生成100条原始特征、100×50对齐特征、5000条来源映射和100行汇总；程序重算校验为0错误，原始媒体仍有7项质量提示。现有对齐等级为完整词级70条、部分词级15条、仅片段级15条；13条视频整段未检出人脸。阶段5要回答“文件是否可信、对齐方案如何比较、哪些结论仍需要人工证据”，不训练情感预测器，也不用情感标签选方法。

## 1. 本阶段的交付边界

阶段5分三层，报告必须分开写：

1. **程序硬检查**：100个ID、5000个窗、源索引、形状、边界、掩码、有限值、可重复性。可以自动给出通过/失败。
2. **方案对照与稳健性**：在同一100条、同一批阶段2原始向量、同一50窗和同一缺失规则下，比较主方案与一个简单基线；给出覆盖、可追溯性、时间定位、运行代价和差异。没有独立真值的指标只称为代理量或描述统计。
3. **人工听看抽查**：产出待填写的核查表与典型样本时间图；由人对原MP4确认词、声音、画面是否对应。未填写和复核前，状态为“待人工”，不能写“通过”或“真实对齐误差”。

## 2. 候选方案及公平对照

| 方案 | 固定规则 | 用途与限制 |
|---|---|---|
| A：当前主方案 | 使用阶段3既有交叠秒数加权；视觉使用5 Hz源帧的最近代表区，左右最大0.1 s；人脸/场景分别聚合。 | 保留词跨窗与部分覆盖，作为当前交付主线。 |
| B：中心点入窗基线 | 保持**同一**50窗边界、同一原始向量和同一来源有效掩码。词和音频源区间取中点，视觉取真实采样PTS；每个来源只归入中点所在的一个窗，窗内算术平均，空窗保持缺失。 | 是“固定50窗均匀池化”的明确可复现版本，不按序列索引假造时间。长词或跨窗声学帧只归一窗，可能损失边界信息。 |
| C：线性重采样（条件对照） | 仅对连续数值模态中的音频与全画面，在相邻且均有效的源点之间对50窗中心线性插值；不外推、不跨越缺失段；文本和人脸沿用A，不把词向量或无人脸片段插值。 | 只作为音频/场景的局部对照，不能宣称是完整三模态新方案。先完成A/B后，确有分析价值再做。PCHIP暂不列首轮必做。 |

B的零基分窗为 `k=min(49, floor(50 c_j/T_i))`，`c_j=(a_j+b_j)/2`（视觉用实际PTS）。所有方案保留 `alignment_level`、整段文本退化和人脸缺失的原始状态；仅片段级样本使用同一 `clip_text` 复制策略，部分词级样本不填造缺失词时。比较时不能让B改用不同编码器，也不能让C额外使用任何情感标签。A/B必须生成可回查的来源索引；C若运行，也要保存两侧源点与插值系数。

候选数组可在计算时逐样本临时生成；正式 `outputs/stage3/features_aligned_50.npz` 不覆盖。首轮只保存比较指标和必要的典型样本小片段，不额外保存第二个100×50大文件，以免挤占后续附件体积。

## 3. 预先固定的检验与指标

### 程序硬门槛

- 先运行现有 `src/validate_outputs.py`：100条ID与顺序一致、5000条映射可回算、(100,50,768/18/628)形状正确、时间在各自 `[0,T_i]`，数组无NaN/Inf、无来源的零值有相应掩码。失败则停止比较。
- 检查情感标签字段没有进入阶段3/5特征、阈值或方案选择代码；保留原始文件哈希和已锁定配置。
- 典型样本以相同输入复跑A，比较ID、时间、掩码完全一致，浮点特征在约定容差内一致；必要时说明压缩NPZ的字节哈希不等于数值一致性。
- 对候选B使用合成测试：源区间中心恰落窗界、跨窗长词、空窗、静音、无人脸但有场景、片段文本退化；不把无基频误作音频缺失。

### 同口径比较表

每条样本、每个候选方案分别统计词级可定位窗、片段退化窗、音频有来源窗、全画面有来源窗、人脸有来源窗，以及非退化有值窗的可回溯比例；全体100条给出总量和分布，而不是只报平均值。音频覆盖用区间并集长度/窗长；基线中点归窗的“有值窗率”与A的“真实时间覆盖率”是两种指标，表中分栏，不混为一谈。

在A/B**共同有来源**的窗内，分别按模态报告向量差异的中位数与分位数；它只描述算法输出差别，不是对齐准确率，也不能跨768/18/628维直接比较数值大小。报告运行秒数、暂存字节数、可回溯比例、窗覆盖和退化样本数。若采用源特征重构残差，它会因A本身是重叠加权均值而天然偏向A，只能作内部一致性量，不能当作独立胜负依据。

### 稳健性

固定规则、固定样本集，考察时间边界 ±10 ms 的扰动（裁于有效区间、保持 `start<end`），记录掩码改变比例与共同有效窗特征差异；另以 `K=40/60` 重算覆盖率与来源定位作敏感性展示，但正式交付仍是 `K=50`。视觉代表半径单独做 0.08/0.12 s 检查，不能和改变聚合算法的效果混算。扰动不得根据情感标签调节，也不得覆盖原时间轴或正式输出。

## 4. 人工抽查与图示

预先固定六个核查样本，避免只挑好看的例子：完整词级典型 `-3g5yACwYnA$_$13`、短片段 `-mJ2ud6oKI8$_$6`、长片段 `-yRb-Jum7EQ$_$1`、仅片段级 `-HwX2H8Z4hY$_$2`、部分词级 `-aqamKhZ1Ec$_$0`、无人脸 `-HwX2H8Z4hY$_$9`。如一条兼有多种问题，照样保留，不临时替换；需追加样本则在报告中写明原因。

生成一张典型样本同轴图：50窗边界、词区间/无词标记、音频能量或有声比例、抽帧PTS及人脸掩码，标出若干来源帧号。图形仅展示程序位置；人工须打开原MP4，在相应时刻听语音、看画面，对至少一个完整词级样本和各类异常样本记录核查。人工表建议字段：`sample_id,bin_index,source_word_index,automatic_start_s,automatic_end_s,manual_start_s,manual_end_s,visual_frame_index,review_status,issue_note,reviewer_code`。空白人工列不得自动填“正确”或制造零误差；不公开个人姓名。

词时间人工偏差只适用于人工标出的词或事件，并以“抽样核验偏差”称呼。A/B共用同一阶段1词时间，源词偏差不能拿来证明某个**聚合**方案更优；如比较窗级归属，应在已人工核实的事件上另算事件与候选窗的覆盖/时差，并清楚标明核查样本数。对于仅片段级和无人脸样本，重点核对缺失标记是否诚实，而不是硬造词级或面部真值。

## 5. 计划代码、文件和实施顺序

最小实现：新增 `src/evaluate_stage5.py`，读取已验证的阶段0—4产物，先算B及A/B比较表，可选择执行C和敏感性；复用现有 NumPy/PyAV/标准库与 `src/align_50.py` 的时间工具，不另起复杂评估框架。给 `tests/` 添一项小型确定性测试。人工表与同轴SVG由脚本生成；人工填写和核查结论由人完成。

| 计划文件 | 含义 |
|---|---|
| `outputs/stage5/qa_100.csv` | 100条程序质量指标及原有异常；不含人工“通过”判断。 |
| `outputs/stage5/compare_100.csv`、`comparison_report.json` | A/B逐样本与全体比较，指标定义、限制和运行代价。 |
| `outputs/stage5/sensitivity.csv` | 固定扰动与K/视觉半径试验；若某项未运行必须标明未运行。 |
| `outputs/stage5/manual_review_template.csv`、`typical_sample.svg` | 待人工填写的核查清单与可读时间图；不伪造人工结果。 |

执行顺序：① 现有全量校验通过；② 合成边界测试；③ 六样本预览并人工检查图/源索引；④ A/B全100样本比较；⑤ 可选C与敏感性；⑥ 汇总限制、等待人工回填；⑦ 仅在人工记录存在后写抽样核验结论。程序完成的验收条件是100条对比行、指标分母明确、无标签泄漏、原始产物未覆盖、所有硬检查通过；**人工核验完成**另设条件，不由脚本自动宣称。

方案推荐原则：先满足来源可追溯、时间/缺失状态真实、100条覆盖的硬门槛；再结合人工核查和稳健性判断。若B只是更快但损失跨窗信息，维持A；若C只让部分连续模态的图变平滑而没有更好独立证据，不替换A。不设计任意加权总分，也不把向量差异或情感标签拟合结果当成真实对齐精度。
