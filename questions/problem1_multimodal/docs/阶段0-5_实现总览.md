## 计算口径与解释边界

- A方案的第 `k` 窗与第 `i` 个来源区间的权重为两区间交集时长；窗向量为有效来源向量的加权平均。无有效来源时，值保持零且观测掩码为假。音频覆盖率使用来源区间并集，避免重叠音频帧重复计时。
- B方案把词或音频来源的时间中心、视觉来源的实际 PTS 分配到单个窗，窗内取普通平均。A/B的来源特征、样本和目标窗相同，比较仅隔离时间归窗规则。
- A/B有效窗数分别为：文本3439/1556、音频4960/4953、全画面4997/3440、人脸3942/2795。A的窗占用较多是方法性质，不能直接当成真实覆盖更好或识别更准；向量差异也不是对齐准确率。候选C（局部插值）未运行。
- 7条媒体警告由5条容器流时长与解码时长差异、2条超出题面时长范围组成；警告样本仍保留。词级时间来自自动强制对齐，尚无人工真值。人工复核模板当前仍为“待人工”。

## 代码与复现入口

六个主脚本按顺序运行：`src/build_manifest.py` → `src/build_timeline.py` → `src/extract_features.py` → `src/align_50.py` → `src/validate_outputs.py` → `src/evaluate_stage5.py`。详细命令、依赖和模型版本见项目根目录 `README.md` 与 `project.toml`；各阶段设计和运行报告也在本目录。`tests/` 提供无需读取100条视频的边界单测。阶段1/2和阶段3可分别运行试验子集，正式全量产物存放在 `outputs/stage*`。

下一步应填写 `outputs/stage5/manual_review_template.csv`，抽查词时间、画面源帧、人脸漏检与异常时长；据此决定是否修正自动对齐或调整代表区。之后再进行情感识别建模，不能把本阶段的结构自检写成下游识别精度结论。
