# 问题一阶段3—4运行报告

本报告对应已运行的代码与本地附件1的100条原始视频。阶段3将既有三模态原始时间序列统一到每条视频的50个时间窗；阶段4写出全量汇总和可追溯映射。阶段0—2输入保持只读，情感标签未参与聚合。

## 实际产物与结果

| 产物 | 实际结果 |
|---|---|
| `outputs/stage3/features_aligned_50.npz` | 100条×50窗；文本768维、音频18维、视觉628维；含独立模态/人脸/片段退化掩码。17,903,473字节。 |
| `outputs/stage3/alignment.jsonl` | 5000条窗级来源映射，含词索引与交叠、音频帧索引范围、视觉源帧号、缺失原因。1,584,318字节。 |
| `outputs/stage4/summary_100.csv` | 100行全量汇总，含原始长度、对齐等级、各模态覆盖及质量状态。 |
| `outputs/stage4/report.json` | 样本/窗口统计、异常分类和最终程序校验结果：`validation_status=passed`，错误数0。 |

全量50窗中，3439窗有词级定位文本，750窗使用仅片段级文本退化输入；其余811窗无可定位词，不能统一解释为“无讲话”。音频有来源4960窗，平均时间覆盖率0.981964；全画面有来源4997窗，人脸有来源3942窗。100条样本中68条状态正常、32条需复核；复核是词时间等级或原始人脸缺失等质量标记，**不是**输出失败。来源问题计数为：仅片段级词时间15条、部分词级15条、整段无人脸13条、题面时长范围不符2条；这些类别可以重叠。

窗边界按阶段1共同时间轴的实际 T_i 等分，源区间按交叠秒数加权。5 Hz视觉抽帧使用最多左右各0.1秒的最近帧代表区，并裁于末个实际解码帧；人脸52维与全画面576维分别聚合。原始声学帧互相重叠，音频覆盖率计算区间并集，不把权重总和误当时长。具体公式、退化与空窗语义见[阶段3—4设计](阶段3-4_实现前规划.md)。

可追溯例：样本 `-3g5yACwYnA$_$13` 的第0窗为 0.000000—0.110280秒；对应词索引0、音频帧半开范围[0,12)、视觉原视频帧号0和6。词权重及其他映射位于 `alignment.jsonl`；时间和特征可在该样本的 timeline JSON 与原始 NPZ 中重算。这展示了文件契约，不是人工听看后的对齐精度结论。

## 验收与限制

在工程根目录运行 `.\.venv\Scripts\python.exe src\align_50.py` 后，运行 `.\.venv\Scripts\python.exe src\validate_outputs.py`；后者对100条样本重新聚合，逐项核对总NPZ、5000条映射与100行汇总。最终校验退出码0，阶段0—2原有7项媒体质量提示仍在 `outputs/validation/report.json`，没有被阶段3消除。测试 `.\.venv\Scripts\python.exe -m unittest discover -s tests -v` 的5项检查全部通过。

当前 `outputs/` 连同6样本试跑文件约47.24 MiB；这不是最终竞赛附件的打包尺寸，仍须连同其他待提交材料核对赛题的总附件限制。本轮没有人工逐词听看、视觉漏检复查、插值对照或敏感性分析；不能把程序结构校验写成情感识别效果或全量时间真值验证。
